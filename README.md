# Machine Learning, Gen AI & LLMs for Business Applications

A learning repository created as part of a Generative AI and Machine Learning certification program by IIT Madras. This repository contains hands-on experiments, implementations, and practice exercises focused on understanding modern AI concepts and applying them through practical examples.

## Overview

This repository documents my learning journey in:

* Generative AI concepts
* Machine Learning fundamentals
* Large Language Models (LLMs)
* AI-powered application development
* Practical experimentation with AI tools and frameworks

## Goals

* Build a strong foundation in Machine Learning and Generative AI.
* Understand how modern AI systems work.
* Experiment with AI workflows and real-world use cases.
* Explore opportunities to integrate AI capabilities into software applications.

## Tech Stack

* Python
* Machine Learning libraries
* Generative AI tools and frameworks
* Jupyter Notebooks
